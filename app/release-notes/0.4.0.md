- Timeline (⌘9): every 10 seconds Gauge saves which apps were busiest, and notes sleep, wake, apps opening and quitting, and heat. Go back to any moment to see what was running, and follow battery health and disk use over months.
- Worth a look flags an app whose memory keeps growing, CPU that's higher than usual for this Mac at this time of day, battery used while the Mac was asleep and what woke it, and an app holding a quarter of your memory.
- Thermal state: Gauge says when macOS is slowing the processor to manage heat.
- Notifications, if you turn them on: a macOS notification when an app holds a lot of memory or pins a core, memory pressure stays high, or the startup disk is almost full. Each is sent at most once an hour.
- Projects shows who holds each dev port and flags servers left running in old projects, lists Docker, OrbStack, Colima and Podman containers, measures build caches with Move to Trash, and estimates how large a local AI model fits in memory.
- The gauge command and an MCP server let Terminal and coding agents read Gauge. They're off by default, read-only, and use a socket only your account can open.
- The status bar counts every network request Gauge makes, and the Privacy sheet lists each one.
- A redesigned Settings window, with Open at login and a Local tools pane.
